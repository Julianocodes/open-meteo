# 🌤️ Consulta de Clima

Uma aplicação web simples para consultar informações climáticas de diferentes cidades, desenvolvida com o objetivo principal de praticar o consumo de APIs e fortalecer meus conhecimentos em JavaScript.

## 📌 Sobre o projeto

Este projeto nasceu de uma vontade: aprender, na prática, como consumir uma API e trabalhar com dados externos em uma aplicação web.

Comecei com o desafio de pesquisar uma cidade, obter suas coordenadas geográficas e, a partir delas, consultar informações sobre o clima atual.

Durante o desenvolvimento, contei com o apoio de uma ferramenta de Inteligência Artificial (IA) para me orientar no passo a passo, ajudando a entender o que precisava ser feito e quais caminhos seguir, sem simplesmente solicitar códigos prontos para copiar e colar.

O resultado é uma aplicação construída com os conhecimentos que tenho até o momento, respeitando meu nível atual de aprendizado.

Poderia ter desenvolvido algo mais elaborado, com mais funcionalidades e um visual mais sofisticado. Sei que a Inteligência Artificial é capaz de produzir soluções muito mais complexas em poucos minutos. Porém, minha intenção foi outra: apresentar algo que realmente desenvolvi, com simplicidade, clareza e, principalmente, aprendizado.

**Este projeto não representa tudo o que a IA pode fazer, mas representa aquilo que estou aprendendo a fazer.**

## 🚀 Funcionalidades

- Pesquisa de cidades pelo nome.
- Busca de coordenadas geográficas.
- Consulta da temperatura atual.
- Consulta da velocidade atual do vento.
- Exibição de mensagens de carregamento.
- Tratamento de erros para cidades não encontradas e falhas nas requisições.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- API Open-Meteo

## 🔌 APIs utilizadas

O projeto utiliza duas APIs gratuitas da Open-Meteo:

- **Geocoding API:** responsável por localizar uma cidade e retornar suas coordenadas geográficas.
- **Weather Forecast API:** responsável por fornecer os dados meteorológicos a partir das coordenadas obtidas.

Documentação: https://open-meteo.com/

## 📚 Conhecimentos praticados

Durante o desenvolvimento, pratiquei conceitos importantes de JavaScript:

- Consumo de APIs com `fetch()`. 
- Programação assíncrona com `async/await`.
- Manipulação do DOM.
- Utilização de `try/catch` para tratamento de erros.
- Eventos de clique e teclado.
- Manipulação de elementos HTML.
- Exibição dinâmica de informações na página.

## ▶️ Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/Julianocodes/open-meteo.git
   ```

2. Abra a pasta do projeto no VS Code.

3. Execute o arquivo `index.html` utilizando a extensão Live Server ou outro servidor local.

4. Digite o nome de uma cidade e clique em **Buscar**.
